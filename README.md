# K53 Prep

An interactive K53 learner's licence quiz built from the *K53 for Learners* manual.

- Choose 20, 50 or 100 questions per attempt.
- Questions are drawn at random from 196 car and light-vehicle questions and shared across the book sections.
- Pictures (road signs, markings, diagrams) come from the book.
- Pick an answer, press **Check answer**, then **Next question**. Pass mark: 75%.

## Run it

Open `index.html` in a browser. It is a single self-contained file with no build step.
